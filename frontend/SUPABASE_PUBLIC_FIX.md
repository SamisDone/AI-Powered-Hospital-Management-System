# Fix: "400 Bad Request" on File View

The "400 Bad Request" error usually happens for one of two reasons when using Supabase Storage:
1.  **The Bucket is NOT set to "Public"**: The code uses `getPublicUrl` (which generates a public link), but the bucket is configured as "Private" in Supabase. Private buckets require signed (expiring) URLs, which don't work well with your current database structure.
2.  **Special Characters in Filenames**: Sometimes spaces or special characters in filenames cause issues.

## Solution 1: Make Bucket Public (Required for `getPublicUrl`)
1.  Go to your **Supabase Dashboard** > **Storage**.
2.  Find the `medical_records` bucket.
3.  Click the **three dots** (`...`) next to the bucket name.
4.  Select **Edit Bucket**.
5.  **Toggle ON** query "Public bucket".
6.  Click **Save**.

*Once this is done, the links generated by your app will start working immediately.*

## Solution 2: Sanitize Filenames (I will apply this to the code)
To prevent future errors with special characters, I am updating the code to automatically remove spaces and special symbols from filenames before uploading.
